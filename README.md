# 115work

面向国内本机和 NAS 环境的 115 离线下载、云解压及本地解压工具。
复用 UnpackFlow 的 xtractr 解压实现，默认不需要安装 7-Zip。

当前为开发验收版本。真实 115 账号、NAS 文件系统和容器环境仍需联调；
镜像构建结果以 GitHub Actions 状态为准。

## 镜像发布

推送到 `main` 后，GitHub Actions 自动构建 amd64 和 arm64 镜像，
发布到 `ghcr.io/zaiwuli/115work`，标记为 `latest` 和提交版本。
实际可用状态以 Actions 构建结果为准。

```powershell
docker compose -f compose.image.yaml up -d
```

通过 `http://设备地址:5656` 直接访问，不需要配置可信网段或网关。
可修改 Compose 的 `ports` 左侧端口改变宿主机端口。
任何能连接该端口的人均可管理后台，请勿映射到公网。
本地卷必须允许容器内 UID 1000 写入。
当前 Compose 使用群晖目录示例：`/volume1/docker/115work` 保存配置与数据库，
`/volume4/存储空间4/解压文件夹` 自动创建监控、解压、缓存、归档和离线磁链目录。
Compose 不挂载 CloudDrive，也不需要 CD2 接口或缓存。
容器名称为 `115work`，部署前请确认没有同名旧容器正在运行。

## 本机启动

需要 Python 3.12 及以上版本。重新构建界面时需要 Node.js 22。

```powershell
.\.venv\Scripts\uv.exe sync --frozen --extra dev --extra p115
cd frontend
npm ci
npm run build
cd ..
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 5656 --workers 1
```

打开 http://127.0.0.1:5656 即可进入后台，默认不需要后台密码或令牌。
免登录模式接受设备地址访问，并保留浏览器跨站请求检查。
115 登录凭据、压缩包密码和 MS 通知凭据与后台管理密码无关。

## 核心功能

### 本次监测与目录调整

默认首页为任务中心，顶部显示运行总览；手动目录扫描与生活事件检查也在
任务中心。成功、失败、处理中、等待分别使用绿色、红色、蓝色和黄色标记。
任务中心可切换解压任务和离线任务，离线列表保留单条重试、全部失败项重试、
删除及关联解压任务。离线下载页只保留链接输入与文件导入，独立文档导入
导航已合并到该页面。界面固定使用浅蓝亮色主题。
系统设置按连接管理、云目录、通知、调度、压缩包密码及运行状态分页配置。
工作日志分为工作详情和最近事件。来源管理支持删除来源，保留真实文件和
已有处理任务；正在扫描或待核对的来源需要等待操作结束再删除。

保存 Cookie 后自动启用连接。配置一个云根目录后，自动创建或复用离线、
解压、归档和失败目录，并保存各目录 CID；可另外添加多个云监测目录。
离线产物与监测目录中的压缩包共用处理规则。

离线输入采用固定窗口：首条任务开始后 4 分 30 秒内归入同一窗口，
第 5 分钟扫描一次，第 10 分钟仅补查一次。新输入不会延长原窗口。
更晚出现的产物可由手动刷新或生活事件监测发现。
生活事件每 30 分钟增量检查一次，也可手动触发；移动到监测目录的
压缩包同样会被接管。该机制不保证规避平台风控。

自动计划和操作审计入口已移除。工作日志可展开查看处理详情。
删除已结束的任务会彻底移除其数据库记录和去重身份，不删除真实文件；
原包仍在监测目录时，下次扫描可能重新解压。运行中或结果不确定的任务
禁止删除，避免产生无法追踪的远端操作。

输出目录默认只用压缩包名，重名时才追加任务短编号。
展开同名根目录默认开启且可关闭，例如 `b/b/c` 可整理为 `b/c`；
禁止递归解压有独立开关。包内重名文件策略暂未调整。

- 离线链接登记、提交、状态查询及关联产物追踪。
- 115 云解压、结果校验及失败后的人工确认。
- 确认后通过 115 直链缓存原包，再用内置 xtractr 解压。
- NAS 或本地目录扫描、分卷识别、密码候选、递归解压及结果校验。
- 复用旧工具的 MS 通知协议。
- SQLite 持久保存任务、步骤、事件、下载进度和产物关联。

CD2 的连接、扫描、刷新、下载及协议实现已移除，不再是运行依赖。
旧数据库结构保留历史字段，避免升级时破坏记录。

## 目录与配置

默认数据目录为 `data`：

- `watch`：本地压缩包来源。
- `inbox/links`：链接文档收件箱。
- `cache`：确认后的原包下载缓存。
- `output`：解压输出。
- `config/115work.db`：SQLite 数据库。

环境变量使用 `WORK115_` 前缀，参见 `.env.example`。
本地解压辅助程序为 `bin/115work-extract.exe`；
使用 `scripts/build-extractor.ps1` 可重新构建，容器构建会自动编译。

程序运行在电脑上时，缓存默认落在电脑数据目录。
要缓存到 NAS，需在 NAS 上运行程序并配置其数据目录，或配置可写的 NAS 路径。
容器内来源路径必须已挂载且对程序可见。
