# 苹果快捷指令上传磁链

后台与界面使用同一个地址、同一个端口，没有另设后端端口。

在快捷指令中使用“获取 URL 内容”：

- 地址：`http://NAS地址:5656/api/v1/offline/import`
- 方法：POST
- 请求正文：JSON
- 文本字段 `text`：填写快捷指令输入或剪贴板中的磁链。
- 布尔字段 `auto_extract`：true，离线成功后自动交给云解压。

不需要 Authorization、Cookie 或管理员密码。
JSON 请求自动使用 `Content-Type: application/json`。

```json
{
  "text": "magnet:?xt=urn:btih:你的磁链哈希",
  "auto_extract": true
}
```

多条磁链使用换行分隔，放进同一个 `text` 字段。
接口返回 202 表示已登记排队，不代表远端下载或解压已经完成。
响应包含 `batch_id`、`queued`、`duplicates`、`invalid` 等字段。
可用 `http://NAS地址:5656/api/v1/offline` 查询批次与处理阶段。

iPhone 需能连接 NAS 地址和端口，并允许快捷指令访问本地网络。
不要把免登录后台直接开放到公网；跨网络使用应通过私人 VPN。
